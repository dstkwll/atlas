# Explore choices and uncertainty

Use when the user is finding a direction, comparing routes or working out which questions matter. Choose a decision map, comparison, branching sketch or another structure that makes the current uncertainty usable.

Start from what is already agreed. Separate candidate directions, assumptions, evidence and open decisions. Show which question can be investigated now and which depends on another answer. When territory is too poorly understood to frame a precise question, label that gap plainly instead of inventing a confident sequence.

Connect an investigation to the choice it informs. Make alternatives comparable on the criteria that matter to this user; disclose missing evidence instead of filling a scorecard with guesses. A proposed option remains proposed until accepted, even if it looks best. When a choice is made, preserve its concise reason and the conditions that might warrant revisiting it.

For example, a new community event may need a map of possible audiences and unanswered needs before there is any useful delivery plan. A venue investigation can appear as active work beside an unresolved location choice. The map should not imply that all alternatives will be executed or that more investigation is automatically authorized.

Check that the user can see what is settled, what is uncertain, and which answer would change the next move. Do not force uncertainty into a completion percentage.
