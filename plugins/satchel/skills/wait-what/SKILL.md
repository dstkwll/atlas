---
name: wait-what
description: Re-explain the assistant's last message when the user cannot follow it; not for surprise or disagreement alone.
---

That last message did not land. **Re-pitch it:** restore the missing context, make the important connection explicit, and use a small example if it helps. Repair the explanation of the current point; keep its uncertainty and consequential caveats. If the confusion exposes a mistake, acknowledge and correct it instead of defending the earlier answer.

Draw on **ASD-STE100 Simplified Technical English** as a style reference: short, direct sentences and consistent terms. Explain necessary technical language; do not claim standards conformance. Use the **ubiquitous language**—the shared terms—already established in this conversation. When a relevant `GLOSSARY.md` exists, use it; follow `GLOSSARY-MAP.md` if it directs you to the right glossary. A missing glossary needs no setup.

Answer the point of confusion directly. Ask a focused question only if you cannot tell which point needs repairing.
