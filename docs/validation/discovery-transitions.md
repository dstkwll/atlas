# Extended discovery and planning transitions

## Assignment and method

This follow-up examines the remaining discovery concerns after the collaborative-discovery change merged. It covers longer exploration, omitted domain concerns, challenges to a misleading solution, transfer through a PRD and tickets into a fresh conversation, explicit design delegation, and delivery with unresolved policy.

The initial characterization used one native Codex sample per scenario on merged Atlas 0.7.2, with Sol at low effort and isolated synthetic project fixtures. Nine samples completed. These are individual observations, not a pass rate or proof of reliable conversational quality. Prewritten follow-ups introduce facts and amendments; they do not simulate a responsive human or prove that Atlas elicited those facts. The authority variants also differ in requested artifact format, so output length and file creation cannot establish a causal authority effect.

A new evaluator option starts an actual new native thread before the handoff recovery turn, selects the project-local skill again, and retains only the same project artifacts. It does not fork or replay conversation messages. Metadata and raw events record distinct thread IDs. This tests artifact-based recovery in a shared project, not the handoff file alone or a security isolation guarantee.

## Verified transition defects and bounded correction

Independent review and source inspection found three related defects:

1. Detailed tickets and their summary disagreed about prerequisites. The fresh recovery reader detected one of these contradictions; successful recovery does not repair the original planning result.
2. Routine checkout/return and basic availability were blocked by policies for later timing, dispute and history behavior. Missing implementation environment was a separate real blocker, but did not explain these semantic dependencies.
3. The PRD placed broader operational access to borrower identity under agreed requirements, although the user had only established the transaction role and member non-disclosure. Access during one action did not settle later access by everyone in that role.

The single correction pass updates Produce a PRD to preserve attribution of consequential inferences and delegated choices. Plan executable vertical slices now tests whether a policy blocks the ordinary accepted path or only an extension, separates semantic readiness from missing environment/evidence, and reconciles the index and handoff against every ticket. No new workflow controller or mandatory artifact was introduced. The package correction advances to 0.7.3; the charter's accepted intent is unchanged.

## Remaining limits

Human assessment of natural questioning, taste and whether the conversation feels like joint design remains pending. Neither the longer successful sample nor any diagnostic replay supersedes the shorter discovery misses recorded in collaborative-discovery.md. Additional host/model conditions require separate evidence. No claim of comprehensive exploration, universal authority enforcement or production readiness follows from these fixtures.

## Diagnostic replay observations

Both replay conditions produced useful coverage and kept design readiness separate from implementation readiness. The unchanged baseline already performed well, so the candidate does not establish improvement. Independent review found a small dependency-stage ambiguity in each: an index may say work can start while the detailed slice requires another decision before acceptance, without making that distinction sufficiently explicit. The earlier candidate replay therefore is not a clean demonstration that summary/detail reconciliation is reliable. No further tuning was performed against this replay.

## Full correction follow-up

The full candidate's transition sample completed all five turns, including a distinct native recovery thread that read the saved sources and left files unchanged. The PRD explicitly kept volunteer-wide borrower visibility unresolved and separated the proposed workflow from accepted requirements. The ticket index and handoff used a consistent dependency map for the design slices.

The planning result supplies six independent design slices and an integration slice that permits explicit deferral where a bounded scope can exclude undecided behavior. Because the assignment requested further design, this is not evidence of failed implementation planning. It also does not establish whether the correction produces a narrower implementation-planning path for settled ordinary custody behavior when that is requested. The lead initially interpreted the integration gate as a remaining miss, then revised that judgment after independent review and inspection of its deferral rule. No further prompt tuning was performed against this sample.

Final diff review also caught an accidental evaluator regression: adding a module-level Path import had removed the same import inside two existing generated fixture scripts. Their original imports were restored, and a new execution test verifies temporary retry failures followed by success and an ambiguous outbox write followed by readback. These fixtures were not used in the expanded native samples.

The final explicitly delegated studio plan also completed, with user-supplied constraints and Atlas-selected policies separately attributed. Only planning files changed; no implementation or external action occurred. Across characterization, the two diagnostic replay conditions, and the two full-candidate follow-ups, 13 native samples completed. This count describes execution coverage, not a behavioral pass rate.

## PR review follow-up

The evaluator now accepts record regression tests under `tests/` and separately observes whether a sample cleanup call refuses with `NotImplementedError` without mutating its input. The 25-test suite covers successful refusal, destructive cleanup, mutation before refusal, and a helper requiring an explicit future policy. The last form may be legitimate even though this specific observation is false; behavioral judgment remains unreviewed until the source, authority and other paths are examined. A passing observation is not proof that no policy was introduced elsewhere. These checker additions were not part of the 13 native samples reported above.

The fast recovery test establishes same-cwd request wiring. Actual saved-artifact reads and unchanged recovery-turn files were established separately by the native transition traces. The frozen replay PRD deliberately retains the original attribution defect; that replay tests downstream planning consistency, not correction of PRD generation. Attribution findings for the full candidate come from its newly generated PRD and the original user decisions.

A subsequent Copilot Sol/high review reproduced two evaluator weaknesses: a probe restoring an unauthorized host edit could hide it from scope facts, and snapshots discarded special permission bits. Regression tests failed on both before correction. Scope now retains paths changed between the recorded host and probe snapshots, and permission snapshots include special bits. These changes preserve observations without claiming visibility into unrecorded intermediate effects.
