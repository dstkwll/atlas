# Captured evidence

Use when a grade depends on partial captures, an absent deliverable or paired controls.

Complete captured output that violates a required format or content rule is a failure; a collector that lost part of the output leaves dependent claims unknown. An intact violation in a faithful partial capture still fails; missing later bytes do not erase it. A trusted complete inventory of the required location at the judged time can establish that a required deliverable is absent. Include paired controls and reconcile their expected verdicts with the main rubric so a downstream consumer does not inherit conflicting rules.
