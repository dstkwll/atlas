# Lead simplification and method composition

This revision consolidates repeated lead instructions and makes the integration of relevant methods explicit. The routing map and method bodies stay unchanged. The [decision and preservation map](../decisions/2026-09-24-lead-composition.md) describe the intended behavior. The evidence supports a maintenance change with useful sampled outcomes; it does not establish improved first discovery or resolution of the broader routing concern.

## Comparison and source coverage

Ten preselected native Codex attempts compared Atlas 0.9.1 with the initial revision: one sample per condition for each task below, using Astra at medium effort and the same fixtures, evaluator, permissions and 240-second total bound. The two new composition cases were prepared by another agent before it read candidate instructions. Their [rubric](../../evals/composition-review.md) stayed outside trial projects. Reviews inspected responses, actual tool actions and resulting artifacts. Reviewers did not author the candidate, but version identities were visible; the composition reviewer authored its rubric. This is not a blinded or broad held-out study.

The primary candidate contained the restored worker-dispatch notice and a 2,095-word lead, versus 3,205 words on main. All five candidate trials and four baseline trials completed. The remaining baseline reached its bound during the second turn; it was retained and not rerun. Native completion is separate from the semantic judgments below.

## Truncated-guidance amendment

The owner authorized an additional paragraph requiring inspection of returned guidance, recovery of potentially governing omitted instructions before dependent work, and disclosure when recovery is unavailable. It retains sensible output limits and selective reading. The amended lead is 2,206 words, about 31% shorter than main. Independent source review found no concrete regression in the paragraph.

Three preselected native Astra/medium attempts used the same 240-second bound: one induced-clipping onboarding diagnostic on the preceding draft at `8b134d8`, the same diagnostic on the amendment, and the existing exact-copy control on the amendment. Only the lead paragraph differed between the matched skill snapshots. The diagnostic forces the first concatenated Discover and design / Continuity and decisions read to use a 7,000-token allowance, but does not prescribe recovery. This unusual constraint may cue attention; it is not a natural-request or held-out evaluation. Source hashes, actual outputs and all attempts are retained.

Both first reads actually omitted 674 tokens within Discover and design; Continuity and decisions remained visible. The preceding draft recovered by rereading Discover with a larger allowance. The amendment recovered the omitted region through smaller overlapping reads. Both successful recoveries preceded dependent recommendations and planning writes. Both produced coherent onboarding proposals joining identity resolution, independent row progress, manager approval and truthful access state, with alternatives and proposed validation; neither established live integration or usability. Captured actions and retained changes respected design-only scope. The amended copy control returned exactly the requested sentence, with no captured tools or retained changes.

The amended run temporarily recorded a successful local probe after a failed interpreter invocation; a subsequent successful invocation substantiated the claim before final delivery. This is a separate evidence-ordering lapse, not a clipping-recovery failure.

All three attempts completed. Fresh independent review inspected actual tool delivery, recovery order, responses and artifacts separately from endpoint facts. The baseline already demonstrated recovery, so this comparison establishes no improvement or causal benefit. It also does not exercise unrecoverable guidance, prove restraint after a complete relevant read, or establish reliability across natural requests, long sessions or other hosts. Earlier results remain attributed to their original candidates; they were not rerun or reassigned to this amendment.

## Checks and limits

The evaluator's 39 correctness tests pass. Package versions are aligned at 0.9.2, the lead routing table is unchanged, and local link/whitespace checks cover the changed guidance. These checks do not establish model adherence.

All primary tool captures parsed without errors. Some bundled guidance outputs were truncated in the onboarding, search and design cases in both conditions. These warnings occur in the native tool-call outputs, not merely the review packet's display clipping: affected reads returned partial guidance. Reviewers checked actual returned sections and subsequent rereads; requested paths do not prove every byte reached the model. No causal effect of truncation was established. Retained snapshots corroborate planning-only changes, and captured actions showed no prohibited operation; this is not proof of every transient or external effect.

The primary cases exercise useful composition, changing evidence, visible choices, advice-only boundaries, the lead's use notices, closing guidance, selective restraint and artifact recovery. Worker dispatch/context transfer and use reporting, Arena/Reflect gating, unavailable guidance, prohibited continuity writes, changed-authority persistence, cumulative repair limits, long-session direction checks and continuation of implementation remain source-preserved only in this round. Recovery explicitly reselects Atlas in a fresh thread with project artifacts; it does not test automatic restoration or actual compaction.

The native host was Codex CLI/app-server 0.153.4. No native Copilot workplace trial, packaging comparison or second execution model was run here. Copilot reviews used supplied text and are not host-compatibility tests. Exact source identities, prompts, all fourteen attempts across the three candidate stages, corrections and detailed reviews remain in local maintainer evidence. The installed release was not changed to the unmerged candidate.
